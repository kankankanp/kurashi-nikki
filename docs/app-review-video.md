# TikTok App Review demo video

録画前にTikTok Developer PortalをSandboxへ切り替え、テストユーザーを登録する。動画にはブラウザのアドレスバーを含め、`kurashi-nikki.vercel.app` 上の実装であることが分かるようにする。

1. Kurashi Nikkiを開き、未連携状態を映す。
2. 「TikTokと連携」を押す。
3. TikTokの認可画面に表示されるアプリ名と要求スコープを映し、許可する。
4. Kurashi Nikkiへ戻り、接続先の表示名とアイコンを映す。
5. 所有確認済みURLの写真を入力し、画像プレビューを一枚ずつ確認する。
6. タイトル・説明文を編集し、AI生成・商用コンテンツの表示と送信同意を映す。
7. 「TikTokの下書きへ送る」を押し、公開IDが表示されるまで映す。
8. TikTokアプリの受信箱を開き、届いた下書きを確認する。

Macでは `Shift + Command + 5` から画面全体を収録する。個人情報、Client Secret、アクセストークン、Developer PortalのCredentials欄は映さない。
